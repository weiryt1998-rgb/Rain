# Rain — อากาศสุโขทัย

เว็บดูสภาพอากาศและพยากรณ์ภาษาไทยสำหรับทั้ง 9 อำเภอในจังหวัดสุโขทัย เขียนด้วย HTML, CSS และ JavaScript ล้วน ไม่มีขั้นตอน build ดึงข้อมูลจริงจาก Open-Meteo ผ่านเบราว์เซอร์โดยไม่ต้องใช้ API key และติดตั้งเป็นแอป (PWA) บนมือถือหรือคอมพิวเตอร์ได้

## เปิดใช้งาน

ติดตั้ง Node.js เวอร์ชัน 22 ขึ้นไป แล้วรันในโฟลเดอร์โปรเจกต์:

```sh
npm install
npm start
```

เปิด [http://localhost:4173](http://localhost:4173) เบราว์เซอร์ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดพยากรณ์ล่าสุด หยุดเซิร์ฟเวอร์ด้วย `Ctrl+C` เปลี่ยนพอร์ตได้ด้วยตัวแปร `PORT`

จะนำไปวางบนโฮสต์ไฟล์สถิตใดก็ได้ (GitHub Pages, Netlify, Cloudflare Pages ฯลฯ) โดยอัปโหลดไฟล์ในโฟลเดอร์นี้ยกเว้น `node_modules/`, `scripts/` และ `tests/` ควรเปิดผ่าน HTTPS เพื่อให้ฟังก์ชันตำแหน่ง, service worker และการติดตั้งแอปทำงาน

### เว็บออนไลน์

เว็บเผยแพร่อัตโนมัติผ่าน GitHub Pages ที่ **https://weiryt1998-rgb.github.io/Rain/** — ทุกครั้งที่ push ขึ้น `main` workflow ใน [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) จะรันชุดทดสอบทั้งหมดก่อน แล้วจึงคัดเฉพาะไฟล์ที่เบราว์เซอร์ต้องใช้ไป deploy (ไม่รวมสคริปต์พัฒนา เทสต์ และบันทึกที่มาภาพ) หากเทสต์ไม่ผ่านจะไม่ deploy ดูสถานะได้ที่แท็บ Actions ของ repo

## ฟังก์ชัน

- สภาพอากาศปัจจุบัน อุณหภูมิที่รู้สึกได้ สูงสุด/ต่ำสุด โอกาสฝน ปริมาณฝน และลม พร้อมการ์ดที่เปลี่ยนโทนสีตามสภาพอากาศและช่วงกลางวัน/กลางคืน
- พยากรณ์รายชั่วโมง 24 ชั่วโมงพร้อมกราฟอุณหภูมิ/โอกาสฝน/ลม และพยากรณ์รายวัน 7 วัน เลือกวันเพื่อดูรายชั่วโมงของวันนั้น
- รายละเอียด: ความชื้น ทิศทางและความเร็วลม ลมกระโชก ดัชนี UV พร้อมคำแนะนำ พระอาทิตย์ขึ้น-ตกและตำแหน่งบนท้องฟ้า ความกดอากาศ ทัศนวิสัย
- สรุปคำแนะนำประจำวัน (พกร่ม, ระวังฝนฟ้าคะนอง, อากาศร้อนจัด ฯลฯ) จากพยากรณ์ 12 ชั่วโมงข้างหน้า
- ตารางทั้ง 9 อำเภอโหลดในพื้นหลัง ค้นหาอำเภอด้วยชื่อไทย/อังกฤษ หรือใช้ตำแหน่งปัจจุบันเลือกอำเภอที่ใกล้ที่สุด
- บันทึกอำเภอโปรด สลับธีมสว่าง/มืด (ตามระบบโดยอัตโนมัติจนกว่าจะเลือกเอง) และหน่วย °C/°F โดยจดจำในเบราว์เซอร์
- ลิงก์แชร์ได้ (`?district=si-nakhon`) และแชร์ผ่านระบบของเครื่อง
- อัปเดตอัตโนมัติทุก 15 นาทีขณะเปิดหน้า และอัปเดตทันทีเมื่อกลับมาออนไลน์
- ทำงานออฟไลน์ได้: service worker เก็บหน้าเว็บไว้ ส่วนพยากรณ์ใช้ข้อมูลที่บันทึกล่าสุด (ไม่เกิน 24 ชั่วโมง) พร้อมป้ายบอกว่าเป็นข้อมูลเก่า
- คีย์ลัด: `/` ค้นหา · `R` อัปเดตข้อมูล · `T` สลับธีม · ลูกศรซ้าย/ขวาเลื่อนพยากรณ์รายชั่วโมงเมื่อโฟกัสอยู่ที่แถบรายชั่วโมง
- พื้นหลังภาพถ่าย 4K (3840×2160) เปลี่ยนตามสภาพอากาศปัจจุบัน: แดด เมฆ ฝน พายุ และกลางคืน โดยฝนหรือพายุในเวลากลางคืนยังคงใช้ภาพฝนหรือพายุ การเลือกวันพยากรณ์หรือสลับธีมไม่เปลี่ยนภาพของอากาศปัจจุบัน
- ภาพค่อย ๆ เคลื่อนและซูมเบา ๆ พร้อมละอองฝน แสงแดด เมฆหรือหมอกตามสภาพอากาศ โหลดและถอดรหัสภาพใหม่ให้พร้อมก่อนเปลี่ยนภาพ ปุ่มหยุด/เล่นข้างปุ่มธีมจดจำการตั้งค่า และหยุดเคลื่อนไหวอัตโนมัติเมื่อระบบเปิดลดการเคลื่อนไหวหรือซ่อนแท็บ
- การ์ด ปุ่ม และไอคอนเป็นกระจกใสเบลอมองทะลุ (backdrop-filter) ธีมสว่าง = กระจกฝ้าขาว ธีมมืด = กระจกรมควัน เบราว์เซอร์ที่ไม่รองรับการเบลอจะได้กระจกทึบขึ้นอัตโนมัติ
- รองรับการเข้าถึง: skip link, บทบาท ARIA สำหรับ combobox/ป้ายสถานะ, โฟกัสที่มองเห็นได้, เคารพ `prefers-reduced-motion`, สไตล์สำหรับพิมพ์

อำเภอที่รองรับ: เมืองสุโขทัย บ้านด่านลานหอย คีรีมาศ กงไกรลาศ ศรีสัชนาลัย ศรีสำโรง สวรรคโลก ศรีนคร และทุ่งเสลี่ยม

## ข้อมูลและตำแหน่ง

ข้อมูลจาก [Open-Meteo Weather Forecast API](https://open-meteo.com/en/docs) เป็นข้อมูลจากแบบจำลองอากาศ ไม่ใช่ค่าตรวจวัดโดยตรงจากสถานีภาคพื้นดินในแต่ละอำเภอ สภาพอากาศจริงในพื้นที่อาจต่างจากพยากรณ์ได้ ทุกคำตอบจาก API ถูกตรวจรูปแบบและช่วงค่าก่อนแสดงผล ข้อมูลที่ไม่ครบหรือผิดปกติจะถูกปฏิเสธและแจ้งผู้ใช้แทนการแสดงตัวเลขผิด ๆ

ค่ารายชั่วโมงทุกช่องหมายถึงชั่วโมงที่เริ่ม ณ เวลานั้น เช่น ช่อง 14:00 คืออุณหภูมิ ความชื้น ลม และ UV ณ 14:00 ส่วนโอกาสฝน ปริมาณฝน และไอคอนสภาพอากาศคือช่วง 14:00–15:00 (Open-Meteo รายงานค่าฝนของ "ชั่วโมงที่ผ่านมา" ที่แต่ละเวลา `weather-core.js` จึงเลื่อนค่าเหล่านี้ให้ตรงกับป้ายเวลา) ระดับดัชนี UV จัดตามเกณฑ์ WHO บนค่าที่ปัดเป็นจำนวนเต็ม

พิกัดประจำอำเภอเป็นจุดอ้างอิงโดยประมาณบริเวณที่ว่าการอำเภอ อ้างอิง [เอกสารพิกัดของกรมปศุสัตว์ หน้า 7](https://dld.go.th/th/images/stories/about_us/gisdld/06.pdf#page=7) การใช้ GPS เลือกจากระยะห่างถึงจุดเหล่านี้ จึงไม่ได้ตรวจสอบว่าผู้ใช้อยู่ในเขตการปกครองของอำเภอใด

เบราว์เซอร์จะขอสิทธิ์ตำแหน่งเมื่อใช้ฟังก์ชันนี้ และต้องเปิดเว็บผ่าน HTTPS หรือ localhost หากไม่อนุญาต สามารถค้นหาและเลือกอำเภอเองได้

รายการโปรด การตั้งค่า และแคชเก็บใน `localStorage` ของเบราว์เซอร์ การล้างข้อมูลเว็บไซต์จะลบข้อมูลเหล่านี้ หากเบราว์เซอร์ปิดกั้นพื้นที่จัดเก็บ ยังเปิดดูข้อมูลอากาศได้ แต่การตั้งค่าและแคชจะไม่ถูกบันทึก เว็บไม่มีการติดตามผู้ใช้และไม่ส่งข้อมูลไปที่อื่นนอกจากคำขอพยากรณ์ไปยัง Open-Meteo และฟอนต์จาก Google Fonts

บริการ API ฟรีของ Open-Meteo ใช้ได้สำหรับงานที่ไม่ใช่เชิงพาณิชย์และมีข้อจำกัดจำนวนคำขอ ส่วนข้อมูลต้องแสดงเครดิตตาม CC BY 4.0 หากนำเว็บไปใช้เชิงพาณิชย์ เช่น มีโฆษณาหรือเก็บค่าสมาชิก ให้ใช้บริการที่อนุญาตตาม [เงื่อนไข Open-Meteo](https://open-meteo.com/en/terms) และ [แผนบริการ](https://open-meteo.com/en/pricing)

## ความปลอดภัย

- หน้าเว็บประกาศ Content Security Policy แบบเข้มงวด: ไม่มีสคริปต์หรือสไตล์แบบ inline อนุญาตเชื่อมต่อเฉพาะ `api.open-meteo.com` และโหลดฟอนต์จาก Google Fonts เท่านั้น
- ข้อมูลทุกอย่างที่แสดงถูก escape ก่อนใส่ใน DOM และตั้งค่าสไตล์ผ่าน CSSOM เท่านั้น
- เซิร์ฟเวอร์พัฒนา (`scripts/serve.cjs`) เสิร์ฟเฉพาะไฟล์ในโฟลเดอร์โปรเจกต์ ปฏิเสธ path traversal, symlink ออกนอกโฟลเดอร์, ไฟล์ที่ขึ้นต้นด้วยจุด และ `node_modules/`

## ตรวจสอบโปรเจกต์

ชุดทดสอบ Node.js สำหรับตรรกะข้อมูลอากาศและเซิร์ฟเวอร์ ไม่ต้องเชื่อมต่อบริการภายนอก:

```sh
npm test
```

ชุดทดสอบในเบราว์เซอร์จริง (Playwright) ครอบคลุมการโหลดข้อมูล ค้นหา ตำแหน่ง การตั้งค่า สถานะออฟไลน์/ผิดพลาด คีย์บอร์ด และเลย์เอาต์มือถือ โดยจำลองคำตอบจาก Open-Meteo ให้คงที่ จึงรันได้โดยไม่ต้องใช้อินเทอร์เน็ต:

```sh
npx playwright install chromium   # ครั้งแรกเท่านั้น
npm run test:e2e
```

หากมี Microsoft Edge หรือ Google Chrome ติดตั้งอยู่แล้ว ใช้แทนได้โดยไม่ต้องดาวน์โหลดเบราว์เซอร์: ตั้งค่า `PW_CHANNEL=msedge` (หรือ `chrome`) ก่อนรัน เช่น PowerShell `$env:PW_CHANNEL='msedge'; npm run test:e2e`

ตรวจการเชื่อมต่อบริการข้อมูลจริงผ่านเส้นทางโค้ดเดียวกับที่หน้าเว็บใช้ (ต้องใช้อินเทอร์เน็ต):

```sh
npm run check:system
```

## แก้ปัญหา

- ข้อมูลไม่ขึ้น: ตรวจอินเทอร์เน็ตแล้วกดอัปเดต (หรือกด `R`) หากบริการจำกัดจำนวนคำขอ ให้รอสักครู่แล้วลองใหม่
- ป้าย "ข้อมูลเก่า" หมายถึงหน้าเว็บกำลังใช้พยากรณ์ที่บันทึกไว้ ไม่ใช่ข้อมูลที่เพิ่งโหลดสำเร็จ
- หลังแก้ไขไฟล์แล้วหน้าเว็บไม่เปลี่ยน: service worker ใช้กลยุทธ์ network-first จึงควรเห็นไฟล์ใหม่เสมอเมื่อออนไลน์ หากยังไม่เปลี่ยน ให้เปิด DevTools > Application > Service Workers แล้วเลือก Unregister หรือเพิ่มเลขเวอร์ชันใน `sw.js`
- ปุ่ม "ติดตั้งแอป" จะปรากฏเฉพาะเมื่อเบราว์เซอร์รองรับและเปิดผ่าน HTTPS หรือ localhost
